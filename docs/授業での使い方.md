# 授業での使い方（教員用の手引き）

対象：高校2年「論理国語」 原研哉『空白の意味』（教科書 p.145〜151）
準備：教材のリンク（クラスコード入り）、投影用の端末、教科書 p.146〜147 の図版

## 授業のねらい

- 筆者の主張「空白は『無』ではなく、見る側がイマジネーションで満たす可能性（機前の可能性）である」を、体験を通して理解する。
- 「精緻な描き込みを回避することが、見る側のイメージを活性化させる」という逆説を、自分の感じ方の変化として説明できる。

## 準備（前日まで）

1. README の「教員のセットアップ手順」で教材を公開し、GAS を設定する（共有しないなら不要）。
2. 教員用画面でクラスコードを決め、「生徒に配るリンク」を Classroom に投稿する。
3. 前のクラスの投稿が残っていれば「投稿を全消去」「投票をリセット」。
4. 投影する端末で教材を開き、上のバーの **文字 大**（または **設定** →「投影して、みんなで読む」）を押す。本文の要旨は、スマホでは「要旨をひらく」で開くが、「文字 大」では開いたままになる。重い端末なら設定の「絵の描き方」を「軽量」に。投影のときは、舞台の右上の **全画面** を使うと、絵が画面いっぱいに広がる（もどる／Esc で戻る）。
5. 教員用画面の **場面リンク** から、各画面に直接入るリンクをコピーしておくと、授業の途中で配り直せる。

## 50分の流れ

生徒はホームの **はじめる**（途中からは **つづきから**）を押し、各画面の下の道しるべ（**つぎへ ›**）で順に進めます。ホームの「きょうの道のり」には、済んだ項目に印が付きます。

| 時間 | 活動 | 画面 | 発問・指示の例 |
| --- | --- | --- | --- |
| 0〜5分 | うめたい度チェック（前）・補完ラボ | 前／1 | 「白い三角形が見えますか。線は一本も描かれていません」「ぼかし絵は何段階目でわかった？」（クラスの分布が出る）「2コマのあいだで何が起きた？ なぜわかる？」 |
| 5〜15分 | 描き込みスライダー | 2 | 「同じ松です。いちばん松らしいのはどこ？」→ 投票 → 分布を投影。「北宋画・南宋画・破墨は、本文ではどう説明されていた？（148・12／149・2）」 |
| 15〜30分 | 霧の松林をあるく・靄スライダー | 3 | 「奥へ歩いてみよう。白いところに何がある？」「靄を 0 にすると？ いちばん広く深く感じた濃さを記録しよう」「左上の山にはたどりつける？（149・16 霊峰＝白の中の白）」 |
| 30〜40分 | 白の向こうに書く | 4／投影 | 「白い霧の向こうに、何があると思う？ 白い所をタップして一行で」→ 投影モードで読み合う。「同じ白から、どれだけ違うものが生まれたか（150・1／150・5）」 |
| 40〜45分 | 振り返り | 5 | うめたい度（後）→「今日の体験から、空白は『無』ではないと言えるのはなぜか」→ 記録をコピーして提出 |

時間制限はありません。クラスの様子に合わせて、補完ラボや振り返りは短くしてかまいません。

- 霧の松林と投影モードでは **文字を隠す**（または H キー）で、ボタンや文字を消して絵だけを映せます。画面をタップすると戻ります。
- うめたい度チェックは 1〜4 キーでも答えられます。
- 補完ラボでは、予想を書いてから「霧を晴らす」「あいだのコマ」を開くよう指示すると、「自分が補ったもの」が記録に残ります。
- 松風は霧の濃さで音色が変わります（濃いほどこもる）。投影モードの「松風」で教室のスピーカーから流せます。
- 振り返りの記録は **コピー** のほか **ファイルに保存**（テキストファイル）もできます。

## 発問のヒント

- **描き込みスライダー**：精緻な松を選んだ生徒・荒い松を選んだ生徒の両方に理由を聞く。「荒い松のどこに、自分で補った部分があったか」。
- **靄スライダー**：靄 0 の絵は「何でも描いてある」のに、なぜ狭く・浅く感じることがあるのか。本文 150・4「空白地帯を情報のゼロ地帯とは見なさない」と結ぶ。
- **霧の松林**：進んでも進んでも、白の向こうに次の松が現れる。本文 149・7「白い空間は……無数の松を蔵する濃密な奥行き」を体験と結ぶ。
- **白の向こうに書く**：投影された言葉は、どれも「描かれていない」所から生まれた。本文 150・5「意味の比重を加算しようとする心性」とは、まさにこの作業ではないか。

## うめたい度チェックについて

- 6問×1〜4点（合計6〜24点）。21〜24 うめつくし派／16〜20 ちょっと苦手派／11〜15 バランス派／6〜10 余白たのしみ派。
- **どのタイプにも良し悪しはありません**。点数の高い・低いを評価に使わないでください。前後で変わったかどうか、変わったならなぜかを話題にします。

## 実物との見比べ

体験の絵は、松林図をもとに独自に描いた水墨風の絵です。ホームの「**実物を見る**」で、本物の松林図屏風（ColBase の公開画像）を拡大して見られます。番号の印をタップすると、見どころと本文の行（148・12、149・2、149・7、149・16、150・1）が出ます。

- 描き込みスライダーのあと：②の近景の松と、自分が選んだ描き込みを比べる。
- 霧の松林のあと：⑦の霊峰（白の中の白）を探す。見つけるまでの時間を聞いてみる。
- 「教材の霧と本物の余白は、どこが同じで、どこが違うか」を問う。

投影するときは「文字 大」をオンにし、＋で拡大してから横にスクロールすると、屏風の前を歩くように見せられます。

## 屏風モード（第3段階）

ホームの「屏風モード」で、六曲一双を折って立てた 3D の屏風として見られます（絵は本物と教材の創作を切り替え）。

- **全体 → 右隻 → 左隻** の順に見て、屏風は右から左へ見ていくものだと確かめる。
- **斜めから**：となりの扇の松が重なったり離れたりして、白い間合いが変わる（149・7）。
- **座って見る**：畳に座った目の高さ。屏風はもともと座って見る調度でもある。霊峰（左隻の右上）がどう見えるか（149・16）。
- **折り方**を 0°（教科書の図版と同じ平ら）から深くしていき、感じ方の変化を言葉にする。
- スマホでは「傾きで見る」を押すと、端末を傾けて回りこめます（iPhone では許可の確認が出ます）。

古い端末で WebGL が使えないときは、自動で軽い 3D 表示になります。

## 困ったとき

| こんなとき | どうする |
| --- | --- |
| 生徒の画面に「端末内のみ」と出る | 配ったリンク（`?class=…&gas=…`）から開き直す。または教員用画面で URL を設定する |
| 「共有先につながりません」 | GAS のデプロイで「アクセスできるユーザー」を確認。学校のネットワークで script.google.com が開けるか確認 |
| 不適切な投稿が出た | 教員用画面で「非表示」。投影からも数秒で消える |
| 投稿させたくない時間 | 「受付を停止」 |
| 動きが重い | 自動で描画を減らす。古い端末ではリンクの末尾に `&q=0` を付ける |
| 書いた記録を消したい | 端末のブラウザでこのサイトのデータを削除する（記録は端末内にあるだけ） |
