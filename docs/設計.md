# 設計メモ（第1段階）

『空白の意味』（原研哉／教科書 p.145〜151）で使う「松林図を体感するデジタル教材」の設計。

## 1. 画面遷移

`index.html` 一枚。URL のハッシュで画面を切り替える。

```
#/home ── ホーム（クラスコード・授業モード・メニュー・実物の案内）
  ├─ #/check/pre   空白うめたい度チェック（前）
  ├─ #/lab         補完ラボ（見えない三角形 → 半分隠した絵 → ぼかし絵 → マンガの2コマ）
  ├─ #/brush       描き込みスライダー（北宋画 ⇔ 等伯）＋投票ヒストグラム
  ├─ #/forest      霧の松林をあるく＋靄スライダー＋松風
  ├─ #/write       白の向こうに書く（タップ → 30字以内 → 霧に浮かぶ）
  ├─ #/check/post  空白うめたい度チェック（後）
  ├─ #/reflect     振り返り（掛け軸の目盛り・前後比較・テキスト出力とコピー）
  ├─ #/proj        投影モード（言葉が大きく浮かぶ・分布表示）
  ├─ #/byobu       屏風モード（第3段階・準備中）
  └─ #/teacher     教員用（PIN・受付の開始/停止・非表示・全消去・共有先の設定）
```

各体験の冒頭に「本文の該当箇所（ページ・行）」の要旨と「問い」を置く。

## 2. 描画

- Canvas 2D の 2.5D。松は種（seed）から幹・枝・葉群の構造を作り、筆の打ち込み（毛筆を数本〜十数本の「穂」に分けて描き、かすれ＝飛白を入れる）で描く。
- 描き込み度 `d`（0＝精緻、1＝荒い）で、針葉の本数・墨の淡い滲み・荒い打ち込みの本数と太さ・葉群の間引きを連続的に変える。
- 霧の松林は、松をあらかじめスプライト（くっきり版とぼけ版）に描いておき、奥行き `dz` に応じて縮小・透明度（`exp(-k·dz)`）・ぼけを掛けて奥から順に重ねる。通り過ぎた松は奥に生まれ直す。
- 霊峰は画面左上に固定（カメラの前進と無関係なので近づかない）。
- 靄 0 では、山並み・家・道・川・橋・人・鳥・太陽を描き込んだ「説明しすぎの絵」が現れ、松も精緻版に切り替わる。
- 端末の性能（`deviceMemory`・コア数）と実測フレーム時間で、松の数・スプライト解像度・DPR・靄の層を 3 段階で減らす。

## 3. データ形式

### 端末内（localStorage）

| キー | 内容 |
| --- | --- |
| `kuuhaku.v1` | `{ client, classCode, gasUrl, lesson, sound, quality, lab:{kz,hide,blur,manga}, pre:[6], post:[6], mistBest, brushVote, myPosts:[{text,x,y,t}], reflection, lastPostAt }` |
| `kuuhaku.local.<クラス>` | 端末内モードの共有データ `{ open, posts:[{id,text,x,y,t,hidden}], votes:{brush:{client:v}, mist:{client:v}} }` |

`client` は端末ごとのランダムな英数字（名前ではない）。読めない環境でも try/catch で動く。

### スプレッドシート（GAS）

| シート | 列 |
| --- | --- |
| `posts` | id, class, text, x, y, client, time, hidden |
| `votes` | class, client, kind, value, time |
| `classes` | class, open, updated |

## 4. GAS の API

ウェブアプリの URL 1 本。読み取りは GET、書き込みは `Content-Type: text/plain` の POST（プリフライトを避ける）。返り値はすべて JSON（`{ok:true,...}` か `{ok:false,error:"コード"}`）。

| action | 方法 | 入力 | 出力 |
| --- | --- | --- | --- |
| `ping` | GET | — | `{ok, version, time}` |
| `state` | GET | `class` | `{ok, class, open, posts:[{id,text,x,y,t}], votes:{brush:[10], mist:[10], blur:[10]}, n:{brush,mist,blur}, time}` |
| `post` | POST | `class, client, text, x, y` | `{ok, post}` / `error: ng, personal, length, rate, limit, closed, class, client` |
| `vote` | POST | `class, client, kind(brush/mist/blur), value(0〜100)` | `{ok}` |
| `admin` | POST | `class, pin, op, id?` | `op`: `list`, `hide`, `unhide`, `clear`, `clearVotes`, `open`, `close` / `error: pin, locked, nopin` |

- ぼかし絵の `blur` は「n 段階目でわかった」を `n×20−10`（10・30・50・70・90）で送り、10 区分の 1・3・5・7・9 番目を 5 本の棒で表示する。
- 投稿：30 字以内、NG 語・電話番号・メール・URL を拒否、同じ端末は 15 秒に 1 回・1 クラス 10 件まで。
- `state` は CacheService で 5 秒キャッシュし、書き込み時に消す（実行回数とシート読み取りを抑える）。
- 生徒側のポーリングは 8 秒＋ゆらぎ 0〜2 秒。タブが隠れているあいだは止める。
- 教員 PIN はスクリプト プロパティ `TEACHER_PIN`。10 回まちがえると 10 分ロック。
